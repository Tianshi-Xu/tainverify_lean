# Three-model proof compiler acceptance

## Scope

TrainVerify's current development target is a single proof compiler for:

- GPT-2;
- YOCO-MoE-A0.4B;
- YOCO-3B.

Repository publication and pushing `main` are out of scope until every gate in this document passes.

## Shared semantic contract

All three models must use the same canonical graph IR, `evalOp` semantic library, typed ownership/relation system, certificate representation, composition engine, and kernel-audit path. Model configuration may select dimensions and declared input contracts, but must not select model-specific proof code.

Every supported operator must have a source-audited faithful denotation. Every distributed transformation must carry explicit rank, process-group, shape, order, and ownership evidence. Contiguous, replicated, expert-sharded, partially reduced, and zigzag/permuted layouts must remain distinct. Shape equality alone is not value or ownership evidence.

## Mechanical-generation gate

For each model, starting from pinned SM/PM authority artifacts and explicit caller contracts, one documented command must:

1. validate provenance and parse the complete graphs without fallback;
2. infer typed relations over the complete public-target ancestry;
3. emit a deterministic proof-certificate DAG and Lean modules;
4. kernel-check the exact generated bytes under the repository heartbeat and trust policy;
5. produce the public theorem and axiom receipt; and
6. either succeed completely or fail closed at the first localized unsupported, ambiguous, or false obligation.

Acceptance requires:

- zero handwritten model-, Goal-, layer-, node-, or tensor-ID-specific proof modules;
- zero source edits between invocation and result;
- no `sorry`, `sorryAx`, `admit`, user `axiom`, `unsafe`, or `False.elim` in generated proof sources;
- theorem statements unchanged from the authority-derived public contracts;
- ordered rank/TID evidence preserved and rank count derived dynamically;
- each declaration bounded by `maxHeartbeats` in `1..500000`;
- each generated source file smaller than 2.5 MB;
- a second clean invocation byte-identical to the first.

Existing handwritten GPT-2 and YOCO-MoE proofs may be used only as regression oracles while migrating rules. They are not compiler acceptance evidence.

## Model gates

### YOCO-MoE-A0.4B

All five public targets must be generated and kernel-checked by the generic closed-bundle compiler. Existing proof overlays must not be invoked as proof bodies.

### GPT-2

The complete terminal theorem must be regenerated from authority by the same compiler. The legacy per-Goal bridge corpus must not be required by the clean-room invocation.

### YOCO-3B

YOCO-3B is the held-out acceptance model. Its authority and proofs must be regenerated without restoring the removed handwritten/skeleton proof tree. Any newly encountered operator or layout may extend only the shared semantic/rule library and must include model-independent tests.

## Mutation gates

For every model, independently mutate one operator identity, relation/ownership declaration, side condition, graph edge, and certificate. Each mutation must fail at its expected stage with a structured diagnostic that identifies the relevant side, node, tensor, expected relation, actual relation, and considered rule.

## Performance gates

Every clean-room run must record separately:

- authority validation/generation time;
- graph parsing and relation-planning time;
- certificate and Lean-source emission time;
- cold Lean kernel-check wall time and peak RSS;
- warm/incremental kernel-check wall time and cache provenance;
- slowest module and declaration.

No performance claim may be based on resumed or stale `.olean` state. Numerical thresholds must be fixed from reproducible baseline measurements on the designated host before optimization is declared complete.

## Completion boundary

The project goal is complete only when all three models pass the shared mechanical-generation, semantic, mutation, determinism, trust, and performance gates. No repository release or `main` push is permitted before that point.

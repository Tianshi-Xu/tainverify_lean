## Source of truth and side conditions

`denote/GeneratedYOCOMoE.lean` identifies itself as generated by
`Verdict/graph_to_lean.py` from `GeneratedYOCOMoE.manifest.json`; it is therefore
the authority consumed by the new generator. For pilot goal 7747 it yields:

- SM node 275: rank 0, input 5060, outputs `[7747, 7751]`, arity 2;
- PM node 611: rank 0, input 8695, outputs `[15221, 15225]`, arity 2;
- PM node 612: rank 1, input 8696, outputs `[15229, 15233]`, arity 2.

`FaithfulMultirefCertificate` explicitly carries node bounds/equality, arity,
output membership, all three faithful collective exclusions, suffix nonempty
outputs, output freshness, prefix-read nonempty outputs, and input freshness.
These are exactly the premises used by
`denoteGraphDistributedFaithful_reduce1`; they are not hidden behind a one-click
proof macro.

There is no tensor-shape premise for this reduction: `FW_multiref` is exactly
value-preserving (`output = input`), so shape preservation follows by equality.
Reconstruction shape/collective conditions remain obligations of the downstream
lineage theorem and are intentionally not absorbed into this graph certificate.

landed independently, with no Route 1 statement change and no identity-model
